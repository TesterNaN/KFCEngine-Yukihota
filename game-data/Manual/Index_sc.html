★配置需求★

OS Windows98SE/ME/XP/2000/2003（推荐XP以上）
CPU PentiumⅢ800MHz以上（推荐PentiumⅣ以上）
内存 128MB以上（推荐256MB以上）
显卡 800×600，16位色以上（推荐24位色以上）
硬盘空间 300MB以上

★游戏安装★

    直接将压缩包解压到自己指定的游戏目里下即可。
    需要安装.net framework 1.1和directx 9c

★启动游戏★

    直接运行游戏目录下的exe文件即可启动游戏。
    启动游戏后会显示启动选项。

◆手柄选择
    选择游戏中使用的手柄，带振动手柄会有振动效果

◆振动
    对于可振动手柄指定是否在游戏中振动。

◆字体
    选择游戏中使用的字体

◆显示模式
    选择使用全屏幕还是窗口模式启动游戏

◆语言
    选择启动游戏使用的语言

◆不再显示
    选择是否以后不再显示启动选项（不再显示的情况下会使用上一次的设定，手柄在存在的情况下自动选择系统的第一个）

◆手册
    显示此手册


★操作方法★

操作 鼠标 键盘 手柄
选择选项 移动 上下左右键 XY轴（十字键或左摇杆）
决定 左键 回车 按钮1
取消 右键 空格 按钮2
打开弹出菜单 右键 空格  
返回标题画面     按钮10（PS样式手柄Start键）
快进   Ctrl  
隐藏文字窗口   F2 按钮2
切换到快进模式   F3 按钮3
自动播放   F4 按钮4
打开设定选项   F8 按钮9（PS样式手柄Select键）
语言切换   F12  
切换画面模式   Alt+Enter  
结束游戏   Alt+F4  

★弹出菜单★

返回 关闭菜单
选项菜单（F8） 打开选项菜单
画面模式（Alt+Enter） 切换画面模式（全屏模式、窗口模式）。
隐藏（F2） 暂时隐藏隐藏文字窗口。
快进（F3） 进入快进模式。
自动播放（F4） 进入自动播放模式。
语言（F12） 简体中文 显示简体中文。
繁体中文 显示繁体中文。
日本语 显示日文。
字体 设定文字字体。
返回标题画面 返回标题画面。
游戏结束（Alt+F4） 结束游戏。

★标题画面★

New Game 从最初开始游戏。
Short Cut 满足条件后可从故事的中间开始游戏。
Option 打开选项菜单。
Album 可以鉴赏游戏中出现的CG。
Exit 结束游戏。

★选项菜单★

画面效果 淡入淡出 设定显示各种淡入淡出效果以及缩放效果。
气候环境 设定[雪]、[樱花]等的效果。
阳光透射 设定[阳光]的效果。
画面震动 设定[画面震动]的效果。
窗口颜色 设定文字窗口的颜色。
文字速度 设定文字显示的速度。
文字同步 语音同步 台词中文字的显示速度与相应的语音同步。
语音不同步 所有的文字都按照设定的速度显示。
