介紹
------------------------------------------------------------------
秋之回憶2 Pure Story ～雪螢～ 是Memories Off Duet中所附帶的秋之回
憶2的前傳故事。KID Fans Club特別創作組在今年成功推出了其中文影像版
，受到了廣大KID Fans的熱烈歡迎。如今，秋之回憶2 ～雪螢～ 中文PC版
代表了KFC特別創作組自主中文化道路上的一個新的里程碑！
本作品是KFC特別創作組首個完全自主從PS2主機移植到PC主機的遊戲，它的
重大意義在於實現了完全自主的技術漢化工作。本作品的PC版本程序完全是
自主原創，幾乎具備目前KID遊戲官方PC版的全部功能，同時增加了簡體中
文/繁體中文隨時隨地的可切換功能，可以說是適應各種語言玩家的需求！

系統要求
------------------------------------------------------------------
- 最小配置
        CPU PentiumⅢ800MHz以上
        內存 128MB以上
        支持顯卡 800×600，16位色以上
        硬盤剩餘空間 300MB以上

- 推薦配置
        CPU PentiumⅣ以上
        內存 256MB以上
        支持顯卡 800×600，24位色以上，DirectX9兼容顯卡
        硬盤剩餘空間 300MB以上

- 操作系統
        Windows 98SE/ME/XP/2000/2003
        推薦Windows XP SP2


------------------------------------------------------------------
安裝
------------------------------------------------------------------
運行對應語言的dotnetfx.exe安裝.net Framework 1.1，運行對應語言的
langpack.exe安裝語言包。
運行dxsetup.exe安裝DirectX 9.0c。
運行Setup.exe安裝遊戲。安裝時選擇的語言只會影響到生成的快捷方式，
不會對遊戲中的語言選擇造成影響。
請確認遊戲運行前已經安裝.net Framework 1.1和DirectX9c。


------------------------------------------------------------------
卸載
------------------------------------------------------------------
單擊「開始」>「控制面板」>「添加或刪除程序」。
選擇「Memories Off Yukihota」卸載。


------------------------------------------------------------------
運行參數
------------------------------------------------------------------
使用命令行參數/nocopyright可以不顯示版權消息。
使用命令行參數/noop可以不顯示片頭動畫。

已知問題
------------------------------------------------------------------
·日文選項尚未開放。
·聲音播放造成的部分內存洩漏。
·退出遊戲時可能不能完全清除臨時文件。
·遊戲運行過程中由於其它解碼器影響及特殊情況下導致出現無法訪問聲音
文件的錯誤。
·遊戲尚未完全載入情況下最小化，不會自動暫停遊戲。
·淡入淡出情況下單擊鼠標快進會出現短暫顯示錯誤。
