介绍
------------------------------------------------------------------
秋之回忆2 Pure Story ～雪萤～ 是Memories Off Duet中所附带的秋之回
忆2的前传故事。KID Fans Club特别创作组在今年成功推出了其中文影像版
，受到了广大KID Fans的热烈欢迎。如今，秋之回忆2 ～雪萤～ 中文PC版
代表了KFC特别创作组自主中文化道路上的一个新的里程碑！
本作品是KFC特别创作组首个完全自主从PS2主机移植到PC主机的游戏，它的
重大意义在于实现了完全自主的技术汉化工作。本作品的PC版本程序完全是
自主原创，几乎具备目前KID游戏官方PC版的全部功能，同时增加了简体中
文/繁体中文随时随地的可切换功能，可以说是适应各种语言玩家的需求！


------------------------------------------------------------------
系统要求
------------------------------------------------------------------
- 最小配置
        CPU PentiumⅢ800MHz以上
        内存 128MB以上
        支持显卡 800×600，16位色以上
        硬盘剩余空间 300MB以上

- 推荐配置
        CPU PentiumⅣ以上
        内存 256MB以上
        支持显卡 800×600，24位色以上，DirectX9兼容显卡
        硬盘剩余空间 300MB以上

- 操作系统
        Windows 98SE/ME/XP/2000/2003
        推荐Windows XP SP2


------------------------------------------------------------------
安装
------------------------------------------------------------------
运行对应语言的dotnetfx.exe安装.net Framework 1.1，运行对应语言的
langpack.exe安装语言包。
运行dxsetup.exe安装DirectX 9.0c。
运行Setup.exe安装游戏。安装时选择的语言只会影响到生成的快捷方式，
不会对游戏中的语言选择造成影响。
请确认游戏运行前已经安装.net Framework 1.1和DirectX9c。


------------------------------------------------------------------
卸载
------------------------------------------------------------------
单击“开始”>“控制面板”>“添加或删除程序”。
选择“Memories Off Yukihota”卸载。


------------------------------------------------------------------
运行参数
------------------------------------------------------------------
使用命令行参数/nocopyright可以不显示版权消息。
使用命令行参数/noop可以不显示片头动画。

已知问题
------------------------------------------------------------------
·日文选项尚未开放。
·声音播放造成的部分内存泄漏。
·退出游戏时可能不能完全清除临时文件。
·游戏运行过程中由于其它解码器影响及特殊情况下导致出现无法访问声音
文件的错误。
·游戏尚未完全载入情况下最小化，不会自动暂停游戏。
·淡入淡出情况下单击鼠标快进会出现短暂显示错误。
